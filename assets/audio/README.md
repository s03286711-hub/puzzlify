# Puzzlify Audio Assets

Place your audio files in this folder. The app will gracefully skip any missing file.

## Required Files

| File | Description | Recommended Duration |
|------|-------------|---------------------|
| `splash_bg.mp3` | Looping ambient music on splash screen | 30–60s loop |
| `game_bg.mp3` | Looping background music during gameplay | 60–120s loop |
| `tile_pick.mp3` | Short click when starting a drag | < 0.3s |
| `tile_step.mp3` | Subtle tick for each grid cell entered | < 0.1s |
| `connect.mp3` | Satisfying "ding" when two endpoints link | < 0.5s |
| `win.mp3` | Victory fanfare on level complete | 1–3s |
| `button.mp3` | Generic UI button tap | < 0.2s |

## Recommended Free Sources

- **freesound.org** – royalty-free SFX
- **opengameart.org** – game music & SFX
- **zapsplat.com** – UI sounds
- **pixabay.com/music** – background loops

## Tips

- Use `.mp3` format for best compatibility.
- Keep sound effects under 100 KB each.
- Background music should be seamlessly loopable.
- Volume is pre-set: BGM at 35%, SFX at 80%.
